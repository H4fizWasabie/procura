# Procura

<!-- impeccable:product-schema 1 -->

## Platform
web

## Users
The owner and the procurement account at Starlight Veterinary regularly use Procura on desktop.

## Product Purpose
Manage inventory, purchase planning, RFQs and purchase orders, with approvals, payments and supporting reports in the same workspace.

## Operating Context
Daily priorities, confirmed by the user: Purchase orders, Inventory, Planning, then RFQs. Overview remains the landing page.

## Capabilities and Constraints
Keep all existing page routes, API contracts, fields, actions, downloads, permissions and session behavior. The Go server embeds templates and static assets; SQLite is shared with mino. Full feature parity is required before deployment. Production deployment requires a separate decision.

## Brand Commitments
Procura remains the name. The user chose direction A, Grouped Workspaces, from the reviewed HTML concepts.

## Product Principles
- Put frequent work within one click.
- Keep every existing feature findable.
- Confirm saved data and report individual batch failures.
- Preserve list context when reviewing records.
